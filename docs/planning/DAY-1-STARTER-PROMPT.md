## 🎓 Key Learnings (Take Notes!)

### Visual Scripting Structure
```
TRIGGER (When something happens)
  ↓
CONDITION (If something is true)
  ↓
ACTION (Then do something)
```

### Example Script
```
Trigger: When player uses item "Key"
Condition: If player is near door
Actions:
  - Open door
  - Play sound effect
  - Show message "Door unlocked!"
  - Remove key from inventory
```

### Entities in Moddio
- **Units:** Player characters, NPCs, enemies
- **Items:** Collectibles, weapons, keys
- **Projectiles:** Bullets, arrows, thrown objects
- **Regions:** Invisible zones that trigger events
