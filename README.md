## 🎮 Game Concept

### The Solana Universe

**Hub World:** Solana Station (central meeting place)

**Learning Planets:**
1. **Beginner Island** - Blockchain basics (5 lessons)
2. **Trader's Outpost** - DeFi fundamentals (5 lessons)
3. **Developer's Lab** - Building on Solana (5 lessons)
4. **NFT Gallery** - Digital collectibles (5 lessons)
5. **Security Fortress** - Staying safe (5 lessons)

### Core Gameplay Loop
```
Explore 2D World → Meet NPC Teachers → Complete Interactive Lessons
→ Play Mini-Games → Earn Cosmetics + NFT Certificates
→ Help Other Players → Progress to Next Planet
```

### Example Lesson
**Topic:** Understanding Transactions
1. NPC explains concept visually
2. Player practices sending tokens to NPCs
3. Mini-game: Send to 10 NPCs quickly (avoid scammers!)
4. Rewards: Badge + cosmetic hat + progress saved
